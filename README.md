## Featured Projects

### [Relay](https://github.com/LordGrimmXI/relay-event-delivery)

A reliable event delivery platform built with Java, Spring Boot, and PostgreSQL. It persists events, routes them to subscribed destinations, and delivers them asynchronously over HTTP with retry handling, idempotency, and worker-failure recovery.

**Tech:** Java 21 · Spring Boot · PostgreSQL · JDBC · Docker

Key engineering areas:

- Reliable event delivery
- Persistent event state
- Retry and failure handling
- Asynchronous processing
- Idempotency
- Worker recovery
- REST API design
- Database-backed work management

---

### [CHIP-8 Emulator](https://github.com/LordGrimmXI/chip8-emulator)

A CHIP-8 emulator built from scratch in modern C++ to explore low-level programming, CPU architecture, memory management, instruction execution, and emulator design.

**Tech:** C++17 · SDL2 · CMake

Implemented:

- CPU fetch-decode-execute cycle
- Memory management
- Registers and stack
- 34 of the 35 standard CHIP-8 instructions
- 64×32 display rendering
- Keyboard input
- Delay and sound timers
- Unit tests
- Test ROM validation

---

### [MySQL Database Crawler](https://github.com/LordGrimmXI/db_crawler)

A Java/Spring Boot application that connects to a MySQL database, extracts schema metadata, and dynamically generates JPA-annotated model classes.

**Tech:** Java · Spring Boot · MySQL · JPA · JDBC

The project explores:

- Database schema crawling
- Table and column metadata extraction
- Primary and foreign key discovery
- Index inspection
- Dynamic JPA model generation

- Backend tooling

## Running Locally

This is a static HTML/CSS/JavaScript website, so no package installation or build process is required.

### VS Code + Live Server

1. Clone the repository:

```bash
git clone https://github.com/LordGrimmXI/my_resume.git
cd my_resume
```

2. Open the project in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Deployment

The website is designed to be deployed as a static site using GitHub Pages.

After making changes:

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```

Configure GitHub Pages to deploy from the `main` branch.
